# Signy Firefox — экспериментальный порт

Исходный проект: https://github.com/remello/signy.

Изменения: Manifest V3 фонового service worker заменён на Firefox background event script с `type: module`; удалено Chrome-only поле `minimum_chrome_version`; добавлен Firefox Gecko ID и минимальная версия. Код алгоритмов подписи не изменён.

## Тестирование

Откройте `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выберите `manifest.json` в распакованной папке (или XPI, если интерфейс принимает). После перезапуска Firefox временное дополнение удаляется.

ВНИМАНИЕ: Это экспериментальная неподписанная сборка, предназначенная исключительно для проверки совместимости с тестовыми ключами. Не проходила security audit и пока не проверена в настоящем Firefox. Возможны несовместимости `declarativeNetRequest`, `world: MAIN` и динамической регистрации. Не вводите пароль от настоящего ЭЦП.

Чтобы установить постоянно в обычный Firefox, расширение требует подписи Mozilla. `.xpi` здесь — zip-пакет, а не подписанное дополнение.
